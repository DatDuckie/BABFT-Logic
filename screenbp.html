Zero Black-Boxes • Every Gate & SR Latch Explicitly Wired • Additive RGB Pixel Logic

Full Gate-Level Blueprint (5x5 Additive Screen Matrix) EVERY SINGLE GATE EXPOSED

This schematic displays the exact gate-level architecture for a single pixel cell (Pixel X,Y) inside a 5x5 matrix. Replicate this gate setup 25 times to form the full 25-pixel array.

1. Address Matrix Selection Bus

Column Bus (Amber): Wire Switch X1 to AND Gate (In 1) across all Row 1 cells.
Row Bus (Cyan): Wire Switch Y1 to AND Gate (In 2) across all Column 1 cells.
Address Match Line (Deep Purple): Wire AND Gate (X,Y) output to Color Passgates (In 2).

2. Color Passgates & Exploded Memory

Data Line (Magenta): Wire DATA-R, G, B switches into respective AND Passgates.
Set Line (Yellow): Wire AND Passgate output to NOR 1 (In 1) of the SR Latch.
Feedback Loop (Lavender): Wire NOR 1 output to NOR 2 (In 1), and NOR 2 output to NOR 1 (In 2).

3. Display Output & Global Clear

Pure Red Channel: Wire Red NOR 1 output directly to Display Block.
Pure Green Channel: Wire Green NOR 1 output directly to Display Block.
Pure Blue Channel: Wire Blue NOR 1 output directly to Display Block.
Clear Line (Dashed Red): Wire Global Clear Switch to NOR 2 (In 2) on all cells.
